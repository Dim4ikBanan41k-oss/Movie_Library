## Краткое описание программы

Приложение для хранения информации о фильмах с графическим интерфейсом. Позволяет добавлять фильмы (название, жанр, год, рейтинг), просматривать их в таблице, фильтровать по жанру и году. Данные сохраняются в JSON-файл. Присутствует проверка корректности ввода (год — число, рейтинг от 0 до 10).

---

## Инструкция по запуску

### Зависимости
Для работы программы требуется только установленный Python версии 3.6 или выше. Дополнительные библиотеки не требуются — используются только встроенные модули (`tkinter`, `json`, `os`).

### Запуск программы

1. Скачайте файл `movie_library.py`
2. Откройте командную строку (CMD или PowerShell)
3. Перейдите в папку с файлом:
   ```cmd
   cd путь_к_папке
   ```
4. Запустите программу:
   ```cmd
   python movie_library.py
   ```

**Универсальная команда запуска:**
```cmd
python "полный_путь_к_файлу\movie_library.py"
```

## Примеры использования

### Пример 1: Добавление фильма
1. В поле "Название" ввести: `Побег из Шоушенка`
2. В поле "Жанр" ввести: `Драма`
3. В поле "Год выпуска" ввести: `1994`
4. В поле "Рейтинг" ввести: `9.3`
5. Нажать кнопку **"Добавить фильм"**

**Результат:** Фильм появляется в таблице и сохраняется в `movies.json`

### Пример 2: Фильтрация по жанру
1. В поле "Фильтр по жанру" ввести: `Драма`
2. Нажать **"Применить фильтр"**

**Результат:** В таблице отображаются только фильмы с жанром "Драма"

### Пример 3: Фильтрация по году
1. В поле "Фильтр по году" ввести: `1994`
2. Нажать **"Применить фильтр"**

**Результат:** В таблице отображаются только фильмы 1994 года

### Пример 4: Сброс фильтра
1. Нажать кнопку **"Сбросить фильтр"**

**Результат:** Фильтры очищаются, показываются все фильмы

### Пример 5: Ошибка валидации
1. В поле "Рейтинг" ввести: `15`
2. Нажать **"Добавить фильм"**

**Результат:** Появляется сообщение "Рейтинг должен быть от 0 до 10"
